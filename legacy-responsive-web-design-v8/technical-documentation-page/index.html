Pengantar Flexbox

Flexbox (Flexible Box Layout) adalah model tata letak CSS yang dirancang untuk mengatur elemen dalam satu dimensi — baik sebagai baris atau kolom. Flexbox memberikan kemampuan untuk mengatur ruang dan penjajaran item secara efisien.

Dengan flexbox, kita bisa dengan mudah membuat layout yang responsif tanpa harus menggunakan float atau positioning yang rumit.

Model ini sangat berguna untuk:

  • Membuat navigasi menu yang fleksibel
  • Mengatur elemen secara vertikal dan horizontal
  • Membuat layout card yang rapi
  • Menjaga konsistensi jarak antar elemen

Flexbox bekerja pada hubungan parent-child, di mana kontainer flex mengontrol anak-anaknya (flex items).

Konsep Dasar

Ada dua komponen utama dalam flexbox:

  • Flex Container — elemen induk yang dideklarasikan dengan display: flex
  • Flex Items — elemen anak di dalam flex container

Flexbox memiliki dua sumbu utama:

  • Main Axis — sumbu utama sesuai arah flex-direction
  • Cross Axis — sumbu tegak lurus terhadap main axis
.container { display: flex; }

Dengan mendeklarasikan display: flex, elemen anak otomatis menjadi flex items.

Flex Container

Flex container adalah elemen yang memiliki properti display: flex atau display: inline-flex. Properti ini mengubah elemen menjadi konteks flex untuk anak-anaknya.

Contoh penggunaan flex container:

.container { display: flex; background: #f0f0f0; padding: 20px; }

Properti yang berlaku pada flex container:

  • flex-direction — arah sumbu utama
  • flex-wrap — apakah item membungkus
  • justify-content — penjajaran di sumbu utama
  • align-items — penjajaran di sumbu silang
  • align-content — penjajaran multiple baris
  • gap — jarak antar item

Ketika flex container dibuat, semua anak langsung menjadi flex items.

Flex Item

Flex items adalah elemen anak langsung dari flex container. Mereka secara otomatis menjadi bagian dari konteks flex.

Properti yang berlaku pada flex items:

  • order — mengatur urutan tampilan
  • flex-grow — kemampuan item untuk membesar
  • flex-shrink — kemampuan item untuk menyusut
  • flex-basis — ukuran awal item
  • align-self — penjajaran individual item
.item { flex: 1; padding: 10px; background: #4a90d9; }

Setiap flex item dapat memiliki properti yang berbeda, memberikan fleksibilitas tinggi.

flex-direction

Properti flex-direction menentukan arah sumbu utama flex container. Nilai yang tersedia:

  • row (default) — dari kiri ke kanan
  • row-reverse — dari kanan ke kiri
  • column — dari atas ke bawah
  • column-reverse — dari bawah ke atas

Contoh penggunaan:

.container { display: flex; flex-direction: row-reverse; }

Dengan flex-direction: column, main axis berubah menjadi vertikal, mempengaruhi properti lain seperti justify-content.

flex-wrap

Properti flex-wrap mengontrol apakah flex items akan membungkus ke baris berikutnya ketika ruang tidak cukup.

Nilai yang tersedia:

  • nowrap (default) — semua item dalam satu baris
  • wrap — item membungkus ke baris berikutnya
  • wrap-reverse — membungkus ke arah berlawanan
.container { display: flex; flex-wrap: wrap; }

Kombinasi flex-direction dan flex-wrap dapat disingkat dengan flex-flow.

justify-content

Properti justify-content mengatur penjajaran flex items di sepanjang sumbu utama.

Nilai yang tersedia:

  • flex-start (default) — di awal sumbu
  • flex-end — di akhir sumbu
  • center — di tengah
  • space-between — jarak rata, item di ujung
  • space-around — jarak rata di sekitar item
  • space-evenly — jarak merata termasuk ujung
.container { display: flex; justify-content: center; }

Properti ini sangat berguna untuk membuat layout yang rapi dan seimbang.

align-items

Properti align-items mengatur penjajaran flex items di sepanjang sumbu silang.

Nilai yang tersedia:

  • stretch (default) — meregang mengisi ruang
  • flex-start — di awal sumbu silang
  • flex-end — di akhir sumbu silang
  • center — di tengah sumbu silang
  • baseline — sejajar dengan baseline teks
.container { display: flex; align-items: center; }

align-items mempengaruhi semua item sekaligus, berbeda dengan align-self yang individual.

align-content

Properti align-content mengatur penjajaran baris-baris flex items ketika ada lebih dari satu baris (saat flex-wrap: wrap).

Nilai yang tersedia:

  • stretch (default) — baris meregang
  • flex-start — baris di awal
  • flex-end — baris di akhir
  • center — baris di tengah
  • space-between — jarak rata antar baris
  • space-around — jarak rata di sekitar baris
.container { display: flex; flex-wrap: wrap; align-content: center; }

Properti ini mirip dengan justify-content tapi bekerja pada cross axis.

gap

Properti gap digunakan untuk mengatur jarak antar flex items, baik secara horizontal maupun vertikal.

Format penulisan:

  • gap: 20px — jarak 20px untuk semua arah
  • gap: 20px 10px — 20px vertikal, 10px horizontal

Sub-properti:

  • row-gap — jarak antar baris
  • column-gap — jarak antar kolom
.container { display: flex; flex-wrap: wrap; gap: 20px; }

gap menggantikan penggunaan margin pada flex items yang lebih merepotkan.

order

Properti order memungkinkan kita mengatur urutan tampilan flex items tanpa mengubah struktur HTML.

Nilai default adalah 0. Item dengan nilai lebih kecil akan muncul lebih dulu.

.item-pertama { order: 2; } .item-kedua { order: 1; /* akan muncul sebelum item-pertama */ }

Properti ini sangat berguna untuk layout responsif di mana urutan tampilan berbeda pada perangkat yang berbeda.

flex-grow

Properti flex-grow menentukan kemampuan sebuah flex item untuk membesar jika ada ruang kosong di dalam container.

Nilai default adalah 0, yang berarti item tidak akan membesar. Nilai positif (1, 2, dst) menunjukkan proporsi pembesaran.

.item-utama { flex-grow: 2; /* akan membesar 2x lipat dari item dengan flex-grow: 1 */ } .item-biasa { flex-grow: 1; }

Semakin besar nilai flex-grow, semakin banyak ruang kosong yang akan diambil oleh item tersebut.

flex-shrink

Properti flex-shrink menentukan kemampuan sebuah flex item untuk menyusut jika ruang dalam container terbatas.

Nilai default adalah 1, yang berarti item dapat menyusut. Nilai 0 mencegah item untuk menyusut.

.item-tetap { flex-shrink: 0; /* tidak akan menyusut */ } .item-lentur { flex-shrink: 1; /* akan menyusut sesuai kebutuhan */ }

Properti ini berguna untuk menjaga elemen tertentu tetap pada ukuran minimumnya.

flex-basis

Properti flex-basis menentukan ukuran awal sebuah flex item sebelum ruang dibagi oleh flex-grow atau flex-shrink.

Nilai default adalah auto, yang berarti menggunakan ukuran dari properti width atau height.

.item { flex-basis: 200px; }

Ketiga properti flex-grow, flex-shrink, dan flex-basis dapat disingkat dengan flex.

.item { flex: 1 0 200px; /* grow: 1, shrink: 0, basis: 200px */ }
